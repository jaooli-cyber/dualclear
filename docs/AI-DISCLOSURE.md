# AI assistance disclosure

AI assistance was used during precontest research and during the contest build
window.

It assisted with:

- exploring candidate architectures and contest scope;
- drafting specifications, threat models, and adversarial test matrices;
- reviewing Fe APIs and compiler behavior;
- proposing implementation and test changes;
- diagnosing backend-specific failures;
- Red Team review of arithmetic, ABI, native, security, and contest claims;
- preparing documentation, reproducibility commands, and disclosure text.

AI output was not accepted as evidence by itself. The responsible human
participant owns the submission and is responsible for every claim. Source was
reviewed, compiler output was checked, tests were executed on both backends,
artifacts were hashed, and residual limitations are stated explicitly.

Precontest planning is retained outside this repository and is not presented
as contest-window implementation. No secret, private key, credential, or
personal data is intentionally committed.
